# Estructura de las funciones

El programa esta dividido de la siguiente manera:

- NSAGII
- Genetico (reforestación)
- Simulación de los arboles que pueden sobrevivir
- Clasificador
- lectura de bases de datos

Para hacer la lectura de las bases de datos debemos de armar la estructura y cada vez que 
se generen nuevos esta base se debera de actualizar para la inseción o eliminación de los 
datos.

------------------------------------------------------------------------------------

Lo qu voy a hacer con la base de datos es que dado un año vamos a verificar que datos van a sobrevir 
pero los parametros que se colocaron en la simulación sera el tiempo total que duran los arboles vivos 
tomado por meses. 

Entonces vamos a tomar todos los arboles disponibles en el año y se continuara verificando si los arboles 
van a seguir sobreviviendo.
